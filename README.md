# 提示詞排版台 Prompt Blocks

幫不熟 AI 的人把「關鍵字」排成一句能用的指令。

把關鍵字字塊拖進句子的凹槽，即時組出可以貼給 AI 的英文提示詞。
所有關鍵字皆為中英對照，並附上「這一格會改變什麼」的說明。

- **生成圖片**：人物寫真、風景場景、產品照、角色設計
- **生成影片**：一顆鏡頭、產品短片（多了「運鏡」這一類）
- **寫文字**：交辦任務、修改稿件（改用完整句子結構，先指定角色）

單一 HTML 檔案，無相依套件，直接開 `index.html` 即可使用。
