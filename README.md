# 提示詞排版台

幫國中生用 AI 產生作業需要的圖片、影片和文字。把關鍵字字塊拖進句子的凹槽，同時排出繁體中文和英文兩種指令。

## 三種產生方式

- **圖片**：可以切換兩個主題
  - **自創大頭貼**：動漫頭像、動物化身、遊戲角色
  - **空氣過濾創意家電**：產品概念圖、使用情境圖、設計草圖
- **影片**：會動的頭像、打招呼動畫
- **文字**：請聊天型 AI 幫忙想大頭貼點子、改指令

每一格都能自己改字，也能加上自己想到的詞。兩個輸出欄可以直接編輯再複製。排好的內容會存在瀏覽器裡。

單一 HTML 檔案，不需要安裝任何東西，直接開 `index.html` 就能用。
